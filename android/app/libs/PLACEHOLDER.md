# app/libs

`liblotsman.aar` goes here. It is a build artifact, not source — see
[`../../README.md`](../../README.md) for the exact `gomobile bind` invocation.

The directory is committed (with this file) only so that the `flatDir`
repository declared in `settings.gradle.kts` resolves on a clean checkout
instead of erroring on a missing path.
